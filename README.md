# تصميمي — Tasmeemy 2.0

## GitHub
ارفع محتويات المشروع إلى Repository جديد.

## Railway
اختر الـRepository من GitHub، وRailway سيقرأ `package.json` ويشغل:

```bash
npm start
```

لا تحتاج قاعدة بيانات خارجية لهذه النسخة. الإعدادات والطلبات تُحفظ في `data/` على السيرفر.

## الأدمن
افتح:

`/admin`

منه تقدر تعدل اسم الموقع، رقم الهاتف، واتساب، النصوص، الباقات، الألوان، الخطوط، أحجام الخطوط، روابط الصور، الأسئلة الشائعة، وتدير الطلبات وحالتها.

## واتساب
الموقع يسجل الطلب في السيرفر ثم يفتح واتساب برقم الموقع برسالة الطلب. في لوحة الأدمن عند تغيير حالة الطلب يوجد إرسال واتساب برسالة الحالة.

الإرسال التلقائي بالكامل بدون فتح واتساب يحتاج WhatsApp Business Platform/API وحساب/اعتمادات API؛ لا يوجد رابط `wa.me` عادي يستطيع إرسال رسالة تلقائياً في الخلفية.

### تحديث حالة الطلب
عند تغيير الحالة والضغط على حفظ الحالة، يتم تحديث الطلب ثم فتح واتساب برسالة جاهزة للعميل في نفس لحظة الضغط. الإرسال الفعلي يتم من حساب واتساب المفتوح، وليس إرسالاً خلفياً من السيرفر.
